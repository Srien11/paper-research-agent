# 论文研究智能体金标标注指南 v1

## 1. 标注状态

题目只能按以下顺序升级：

```text
silver_generated
→ silver_reviewed（两名标注者独立复核完成）
→ gold_adjudicated（第三名仲裁者处理全部分歧）
```

模型生成的问题、claim 或 span 无论自动校验是否通过，都不能直接标为 `gold_adjudicated`。

## 2. 独立标注流程

1. 冻结语料、解析构建、索引、Schema 和标注指南版本。
2. 两名标注者先独立完成 10–15 条校准题；不查看系统答案和另一人的结果。
3. 每人分别判断 answerability、must-have claim、forbidden claim、证据 span 和引用关系。
4. 合并两人的 claim 候选并去重，两人再次独立判断 `must-have / nice-to-have / forbidden / exclude`。
5. 第三名仲裁者处理 answerability、claim、span 和 citation relation 的全部分歧，并记录原因码。
6. 冻结后才运行正式测试；因模型失败发现的新问题只能进入下一数据集版本。

## 3. Must-have claim

Must-have 必须同时满足：

- 是回答问题不可缺少的事实；
- 是一个可以独立判断真假的原子命题；
- 保留对象、范围、条件、时间、比较方向、数字和单位；
- 至少有一组明确证据支持。

两个可以独立对错的事实必须拆成两个 claim。主观描述如“效果很好”“非常全面”不能作为 must-have。

## 4. Forbidden claim

Forbidden 只标三类高风险错误：

- 与冻结语料明确矛盾；
- 常见但错误的概念混淆；
- 容易说反的数字、单位、因果、比较方向、范围或时间。

“语料没有提到”不等于 forbidden，应交给 Unsupported Claim Rate 评价。

## 5. Span 与引用关系

- Span 使用最短、连续、自包含的原文范围。
- 权威定位为 `paper_id + evidence_version_id + page + element_id + raw offset + span_hash`。
- `chunk_id` 只是当前切分配置的投影，不是唯一权威金标。
- 多段联合才能支持一个 claim 时，必须保留联合证据组。
- 引用关系按 `supports / contradicts / distractor` 标注；主题相似但不能证明 claim 的证据不得标为 supports。
- 图表题应核对原始图注、表格或人工确认区域，模型生成的图片摘要不能单独充当权威证据。

## 6. 不可回答题

正式 20 条不可回答题统一要求 `insufficient_evidence`。每题必须：

- 标注 `unanswerable_reason`；
- 标注最近的困难干扰论文；
- 由 BM25、向量和混合检索分别检查 Top-50；
- 由两名标注者确认不存在足够证据。

系统超时、路由解析失败、服务未启动或 Provider 故障属于系统失败，不能标成不可回答。

## 7. 内部冻结门槛

| 标注内容 | 指标 | 门槛 |
|---|---|---:|
| Answerability | Cohen's κ | ≥0.85 |
| Must-have 集合 | Set F1 / Jaccard | ≥0.80 |
| Span | Token F1 | ≥0.85 |
| 论文与证据选择 | Jaccard | ≥0.90 |
| Citation relation | Cohen's κ | ≥0.75 |
| 数字与单位 | Exact Agreement | ≥95% |

任何未达门槛的维度必须先修改指南、重新校准和复核，不得直接计算正式项目总分。

## 8. 数据安全

原文 span、内部论文派生标签和标注分歧记录只保存在 `data/evaluations/gold/`。公开报告只展示稳定 ID、哈希、数量和聚合指标，不展示内部论文原文、本地路径、问题答案或 Provider 原始载荷。
