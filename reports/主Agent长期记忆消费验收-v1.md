## 安全边界

- 解释器只允许选择本轮实际召回的上下文 ID。
- 未选择的远距历史和长期记忆不会进入子任务。
- 普通聊天、动态工具和本地 RAG 都只消费主 Agent 已选择的记忆。
- 本地 RAG 将长期记忆放入独立的低信任 JSON 消息；记忆正文不进入系统消息。
- `confirmed_conclusion` 必须由本轮论文证据重新核验。
- 引用只接受本轮 evidence chunk，长期记忆 ID 不能成为引用。
- 新增、更新和删除仍要求明确记忆意图与一次性审批；只读搜索不要求审批。
- 观测事件只记录耗时和数量，不记录问题、记忆正文、记忆 ID、数据库位置、凭据或 Provider 原始载荷。

## 尚未完成的真实性能基准

当前环境没有受控且可在验收后安全清理的长期记忆命中样本，因此未执行以下统计，不能宣称达标：

- 有命中场景 5 次运行的水合 P50/P95。
- 历史依赖与长期项目续接各 5 次的选择准确率。
- 无关记忆误选率和真实输入 Token 增量。
- 真实命中场景下的实际消费数。

已扩展无正文冒烟脚本，使其可以运行生产主 Agent、重复采样、复用临时会话，并从安全事件中汇总水合分段指标。获得可控的测试记忆样本后即可补做上述基准，无需再改业务代码。

## 发布判断

代码契约、消费链路、审批边界和故障降级可以发布；真实有命中性能与选择质量仍属于上线后观察项。现有数据不支持转向两阶段渐进水合：单次无命中水合约 49.65 ms，而主请求约 48.69 秒，应先积累有命中 P95 和选择质量数据，再决定是否拆分水合阶段。
