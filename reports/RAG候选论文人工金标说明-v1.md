# RAG 候选论文召回评测集说明 v1

## 数据集构成

- 问题数：30
- 开发集：20
- 封存测试集：10
- 多论文比较题：30
- 标题/摘要/缺摘要回退可识别题：30
- 唯一目标论文：52
- 唯一近邻干扰论文：44
- 难度：简单4、中等15、困难11

## 标注方法

1. 按幻觉与事实性、RAG评估、代码评估、测试集污染、LLM评审、安全、智能体、检索、长上下文和推理自修正等主题分层抽样。
2. 第一轮阅读本地 PaperCard 的标题、摘要；摘要缺失时阅读候选层实际使用的同论文回退文本。
3. 问题不包含 `C001/T001` 等编号，不直接复制完整论文标题，并要求同时召回两篇目标论文。
4. 第二轮从问题反向核对目标论文，检查相似论文是否应作为目标或近邻干扰项。
5. 每篇目标只保存简短释义理由，不保存论文摘要、连续原文或图片内容。

## 数据边界

- 私有金标位于 `data/evaluations/gold/candidate-paper-gold-v1.jsonl`，受 Git 忽略规则保护。
- 封存测试题正文和逐题结果不写入版本库报告。
- 挑战问题、目标编号、标注理由不得进入论文检索索引。
- 本评测集经过题目构造与反向核对两轮一致性检查，未经过独立多人仲裁；后续如需发布正式论文指标，应增加独立复核。

## 指标口径

- Candidate Paper Recall@K：每题目标论文中进入前K名的比例，再做宏平均。
- All-target Hit@K：每题所有目标论文是否都进入前K名。
- 生产可用性和检索上限分开报告：生产配置使用2秒转化截止时间；15秒仅作为无超时诊断，不代表线上延迟配置。
