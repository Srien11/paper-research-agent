# 十九项研究工具平台 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在现有本地 RAG 工具之外，新增 19 个可发现、可审计、受风险策略约束的研究工具，并为联网、计算和写入能力建立关闭失败边界。

**Architecture:** 新增独立 `agent.tooling` 包，将工具契约、风险目录、领域实现、学术 API provider、审批令牌和 LangChain 适配分层。现有 `search_corpus/get_evidence` 保持兼容；新增工具通过统一 registry 暴露，所有调用继续进入结构化事件日志。只读本地工具可直接执行，网络只读工具受域名与超时限制，受限计算只运行固定算法，写入和长期记忆必须携带一次性审批令牌。

**Tech Stack:** Python 3.11+、Pydantic、httpx、LangChain、SQLite、pytest

### Task 2: 本地证据增强工具
