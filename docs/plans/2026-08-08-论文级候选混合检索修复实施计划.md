# 论文级候选混合检索修复 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用“标题+摘要”的论文级 BM25 与向量融合替代偶然原文片段猜测，并为缺失摘要、显式编号和候选边界建立可验证的结构性保证。

**Architecture:** 新增只面向 `PaperCard` 的论文候选文档与混合检索器，运行时加载 `paper_cards.jsonl`，对空摘要卡片使用其 `evidence_chunk_ids` 所绑定的最前几个原文块生成受限回退文本。候选解析器先精确处理显式 `C/T` 编号，否则只消费论文级融合排名；规划器仍只能在候选 `corpus_id` 集合内生成比较目标，后续“论文×维度”原文检索链路保持不变。

**Tech Stack:** Python、Pydantic v2、现有 tokenizer、FastEmbed encoder、BM25、Reciprocal Rank Fusion、LangChain structured output、pytest/unittest、Ruff。
