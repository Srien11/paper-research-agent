# 多论文比较候选发现与分格检索修复 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 先确定性发现问题最可能指向的本地论文，再在严格论文范围内按“论文×维度”独立执行 BM25（关键词检索）+向量混合检索。

**Architecture:** 在 `LangChainResearchPlanner` 前增加只读的论文候选发现器：显式 `C/T` 编号直接解析，隐式问题先用高召回、不做昂贵重排的混合检索按 `corpus_id` 去重，再让独立结构化选择器结合标题与最佳证据摘要选出 2–4 篇。完整规划器只能在该候选中建立目标；比较合约强制每个步骤只覆盖一个目标和一个维度，范围内检索扩大候选后由现有重新排序器统一裁剪。候选不足或有歧义时返回可识别的解析失败，不再抛模糊的通用 `ValueError`。

**Tech Stack:** Python 3.11+ 、Pydantic v2、LangChain structured output（结构化输出）、LangGraph（固定流程图）、BM25、FAISS 向量索引、`unittest`/`pytest`。
