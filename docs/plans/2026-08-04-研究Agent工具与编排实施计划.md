# 研究 Agent 工具与编排 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不改写现有 RAG、引用与版权边界的前提下，增加两个只读研究工具、LangChain Tool 适配器和一个最小可恢复的 LangGraph 顺序研究工作流。

**Architecture:** 领域层以严格 Pydantic 契约暴露 `search_corpus` 与 `get_evidence`，不依赖 Agent 框架；适配层只把领域方法包装成 LangChain Structured Tool；编排层使用 LangGraph 保存结构化计划、逐步执行检索并汇集带血缘的证据。第一版不开放写工具、不引入长期记忆，也不绕过现有最终回答验证边界。

**Tech Stack:** Python 3.11+、Pydantic v2、LangChain 1.x、LangGraph 1.x、unittest、现有 `BilingualRetrievalRun` / `EvidenceChunk` 契约。
