# 动态工具路由与审批恢复 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让研究 Agent 在有界循环内选择扩展工具、按信任类别消费结果，并对写操作执行可恢复人工审批。

**Architecture:** 新增独立 `dynamic` Graph，不破坏现有可引用 RAG Graph。Router 只能输出严格 `ToolDecision`；Runtime 根据 catalog 授权并执行，统一投影为无正文历史摘要。写工具第一次执行仅创建审批请求，Graph 在单独节点 `interrupt`，批准后用原 thread 恢复并消费一次性令牌；拒绝则记录观察并继续或终止。

**Tech Stack:** Python 3.11+、Pydantic、LangChain、LangGraph interrupt/Command、SQLite Checkpointer、FastAPI、pytest

---

### Task 1: 信任与路由契约

创建 `agent/dynamic/models.py`，测试 ToolDecision、ToolObservation、最大步数、工具参数 Schema 二次校验和信任映射。

### Task 2: LangChain Router 与动态 Graph

创建 `agent/dynamic/router.py`、`agent/dynamic/graph.py`，测试只读/网络/计算工具选择、重复调用终止、未知工具关闭失败、结果摘要不保存正文。

### Task 3: interrupt/resume 审批

创建 `agent/dynamic/runtime.py`，测试写工具产生暂停、安全审批 payload、拒绝终止、批准恢复、一次性令牌和 thread checkpoint。

### Task 4: 生产与 Web 接入

修改 Agent factory、Web runtime/app/models 和静态页面，新增启动动态研究、查询待审批、批准/拒绝接口；测试认证、Origin、会话绑定和安全响应字段。

### Task 5: 评测和回归

新增工具路由 fixtures 与选择准确率/越权率指标；更新 README/架构并运行 Agent、Web、全量测试、Ruff 与 diff hygiene。
