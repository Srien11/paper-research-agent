# RAG 回答输入输出 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将已经组装完成的可引用上下文发送给固定版本的千问模型，并输出经过严格引用校验、无证据正文泄漏的结构化中文回答。

**Architecture:** 新增独立 `answering` 包，以 `AssembledContext` 作为唯一模型输入边界。提供方适配器只负责安全调用百炼 OpenAI 兼容接口并返回原始结构化结果；服务层负责证据不足短路、严格 JSON 解析、引用白名单校验和最终答案渲染。第一版只支持 `private_research` 输出，允许发送已加载版权分类的少量命中片段，不新增公开分发接口，也不改变现有索引。

**Tech Stack:** Python 3.11+、Pydantic v2、httpx、百炼 OpenAI 兼容 Chat Completions、unittest、Ruff、mypy。

```python
class AnsweringConfig(FrozenConfig):
    schema_version: Literal["rag-answering-v1"] = "rag-answering-v1"
    model: str = "qwen3.7-plus-2026-05-26"
    prompt_version: Literal["rag-answer-json-v1"] = "rag-answer-json-v1"
    temperature: float = Field(default=0.1, ge=0, le=2)
    top_p: float = Field(default=0.7, gt=0, le=1)
    max_output_tokens: int = Field(default=1200, gt=0)
    timeout_seconds: float = Field(default=30, gt=0)
    max_retries: int = Field(default=2, ge=0, le=5)
    enable_thinking: Literal[False] = False
```

回答契约使用结构化 claims，不允许模型自由拼接引用：

```python
class AnswerClaim(FrozenContract):
    text: str
    citation_ids: tuple[str, ...]

class ProviderAnswer(FrozenContract):
    answerable: bool
    claims: tuple[AnswerClaim, ...]
    insufficient_reason: str | None

class RAGAnswer(FrozenContract):
    schema_version: Literal["rag-answer-v1"]
    status: Literal["answered", "insufficient_evidence"]
    answer: str
    claims: tuple[AnswerClaim, ...]
    citations: tuple[AnswerCitation, ...]
    requested_model: str
    actual_model: str | None
    prompt_version: str
    input_tokens: int
    output_tokens: int
```

`AnswerCitation` 只包含 citation/chunk/corpus/asset/page/hash/type 元数据，不包含证据正文、图片摘要或绝对路径。

```python
async def answer_context(
    context: AssembledContext,
    generator: AsyncAnswerGenerator,
) -> RAGAnswer:
    if context.evidence_insufficient or not context.citations:
        return insufficient_answer_without_provider_call(...)
    generated = await generator.generate(context)
    parsed = ProviderAnswer.model_validate_json(generated.content)
    return validate_and_render(parsed, context, generated)
```

CLI 参数为 `--context`、`--config`、`--output`；API Key 只从 `DASHSCOPE_API_KEY` 读取。输出 JSON 不包含完整上下文和证据正文。

`scripts/rag.py` 提供问题级入口，在一次调用中执行中文问题改写、双路检索、上下文组装、
回答生成和引用验证；`scripts/answer.py` 仅作为预组装上下文的低层调试入口。

SHA-256；禁止保存上下文消息、证据、原始响应或答案正文。审计失败不丢弃已经通过引用验证
的回答，并在结果中保留 `audit_persisted=false`。
