# Compiler 聚合终态统计修正 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修正多论文比较评测把 Compiler 历史失败尝试误报为最终失败的问题，同时保留完整重试过程指标，并在不重新调用模型的前提下离线重算现有 30 题结果。

**Architecture:** 保留每次 `CompilationAttemptDiagnostic` 作为不可变审计事实，但把聚合结果拆为 `attempts`（尝试过程）和 `final`（按题、按 requirement 合并后的事务终态）两层。评测运行格式升级为 `comparison-e2e-run-v2`，继续兼容读取 v1 的 case 诊断；另提供只读输入、另存输出的离线重算脚本，更新整体和分区 Compiler 汇总，不触发检索、Planner、Compiler、回答模型或裁判模型。

**Tech Stack:** Python 3.12、Pydantic v2、JSON、pytest、Ruff、mypy、现有 comparison E2E 评测与安全诊断模型。

---

## 一、问题定义与已确认事实

当前 `aggregate_compilation_audits` 把所有尝试平铺后直接求和：

```python
"failed_unit_count": sum(len(item.failed_requirement_ids) for item in attempts)
```

这能描述“历史上出现过多少次失败单元”，但字段名和门禁报告把它解释为“最终仍失败多少单元”。在本次 30 题结果中：

- 30 题共产生 33 次 Compiler 尝试；
- 3 题触发第二次定向重试；
- 第一次尝试共有 5 个 `fact_chunk_scope_invalid` 单元；
- 第二次重试全部通过；
- 163 个不重复单元最终 163/163 通过；
- 最终失败单元、最终 Schema 失败、最终契约失败、最终未解析事实要求均为 0；
- 最终保留事实为 107 条。

原聚合值 `requested=168 / accepted=163 / failed=5 / unresolved=5` 应保留为尝试过程数据，不能继续作为终态门禁。

## 二、范围与非目标

本计划只修正统计契约和既有结果的离线重算：

- 区分尝试过程指标与最终事务指标；
- 固化审计分区不变量，避免聚合器接收歧义数据；
- 升级运行结果 Schema，并兼容读取旧 case；
- 离线生成本次 30 题的修正版汇总和安全报告。

本计划不修改：

- Planner、Compiler 提示词或重试次数；
- 检索器、Reranker、Top 4、水化策略或查询改写；
- 事实血缘、模型裁判、严格全条件通过率或答案内容；
- `.env`、私有金标、论文正文、索引或 checkpoint；
- 当前工作区中与主 Agent 证据不足状态相关的未提交修改。

实现必须在包含本计划的独立 worktree 中执行。当前工作区已有其他未提交修改，禁止将其带入本修复提交。

**Step 3: 为 `CompilationAttemptDiagnostic` 增加 `model_validator`**

实现最小不变量：

```python
@model_validator(mode="after")
def validate_unit_partition(self) -> CompilationAttemptDiagnostic:
    requested = set(self.requested_requirement_ids)
    accepted = set(self.accepted_requirement_ids)
    failed = set(self.failed_requirement_ids)
    if accepted & failed:
        raise ValueError("accepted and failed requirement IDs must be disjoint")
    if accepted | failed != requested:
        raise ValueError("accepted and failed requirement IDs must partition requested IDs")
    if self.outcome == "validated":
        if failed or self.failure_code is not None:
            raise ValueError("validated compilation attempt cannot contain failures")
    elif not failed or self.failure_code is None:
        raise ValueError("invalid compilation attempt requires failed IDs and a failure code")
    return self
```

保留 `unresolved_fact_requirement_count` 与失败单元数不相等的可能性：一个失败单元可以包含多个未解析原子事实，因此不要增加错误的相等约束。

### Task 3: 实现尝试过程与最终事务的双层聚合

**Step 1: 用 case 内最新尝试建立最终单元状态**

实现时以 `(case_index, requirement_id)` 作为全局键，避免不同题复用相同 requirement ID 时互相覆盖：

```python
def aggregate_compilation_audits(
    cases: Iterable[ComparisonCaseDiagnostic],
) -> dict[str, object]:
    audits = tuple(
        case.compilation_audit
        for case in cases
        if case.compilation_audit is not None
    )
    attempts = tuple(attempt for audit in audits for attempt in audit.attempts)
    final_requested: set[tuple[int, str]] = set()
    final_accepted: set[tuple[int, str]] = set()
    final_failed: dict[tuple[int, str], CompilationAttemptDiagnostic] = {}

    for case_index, audit in enumerate(audits):
        latest_by_requirement: dict[str, CompilationAttemptDiagnostic] = {}
        for attempt in audit.attempts:
            for requirement_id in attempt.requested_requirement_ids:
                latest_by_requirement[requirement_id] = attempt
        for requirement_id, latest in latest_by_requirement.items():
            key = (case_index, requirement_id)
            final_requested.add(key)
            if requirement_id in latest.failed_requirement_ids:
                final_failed[key] = latest
            else:
                final_accepted.add(key)
```

不要只读取 `audit.attempts[-1]` 的 requested IDs：第二次尝试通常只包含第一次失败的子集，第一次已成功提交的单元仍属于最终成功状态。

```python
def recompute_payload(
    payload: Mapping[str, object],
    *,
    source_run_sha256: str,
) -> dict[str, object]:
    cases = tuple(
        ComparisonCaseDiagnostic.model_validate(item)
        for item in payload.get("cases", ())
    )
    updated = dict(payload)
    updated["schema_version"] = COMPARISON_E2E_RUN_SCHEMA_VERSION
    updated["source_run_sha256"] = source_run_sha256
    updated["compilation"] = aggregate_compilation_audits(cases)
    split_summaries = dict(updated.get("split_summaries", {}))
    for split in {case.split for case in cases}:
        split_summary = dict(split_summaries.get(split, {}))
        split_summary["compilation"] = aggregate_compilation_audits(
            case for case in cases if case.split == split
        )
        split_summaries[split] = split_summary
    updated["split_summaries"] = split_summaries
    return updated
```
