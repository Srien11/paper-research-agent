# 生产就绪六项缺陷最小修复 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 以 6 个可独立验证和回滚的原子提交，修复已审查确认的运行数据延续、知识库发布状态、上传与部署权限、会话注销、全局容量和并发发布六项缺陷。

**Architecture:** 保留现有 FastAPI 单进程、SQLite、LangGraph 和 systemd/Nginx 部署形态。可变运行数据与可变知识库放入 release 目录之外的共享目录；进程内使用现有锁和 SQLite 事务补齐状态转换、容量拒绝和发布串行化。不更换数据库，不新增分布式队列，不扩展为多用户系统。

**Tech Stack:** Python 3.11/3.12、FastAPI、Pydantic v2、SQLite/aiosqlite、LangGraph、pytest、Ruff、mypy、Nginx、systemd、Bash。

---

## 1. 执行边界

本计划只修复以下 6 项：

1. 新 release 不延续会话、checkpoint、附件等运行数据，且 Web 默认启动链路绕过部分路径配置。
2. 知识库 API 先写入 `queued`，后台发布却拒绝 `queued`，资料永久卡住。
3. 知识库 100 MiB 应用限制与 Nginx 16 KiB 限制、systemd 只读目录相互冲突，且请求体未在 Web 边界逐块限定。
4. 注销撤销集仅在内存中，服务重启后已注销且未过期的 Cookie 会重新生效。
5. 主 Agent 只限制单会话串行，没有全局在途运行上限，可无界创建任务。
6. 知识库 `corpus_id` 分配、清单写入和索引切换未串行化，并发发布可重号或相互覆盖。

明确不在本次范围：

- 不引入 Redis、PostgreSQL、Celery、Kafka 或其他外部基础设施。
- 不改造 owner-only 身份模型，不开放匿名问答。
- 不修改 RAG 检索、Planner、Compiler、引用或模型提示词行为。
- 不顺手处理依赖告警、评测集规模、依赖锁定、指标看板等审查建议。
- 不改动用户现有的 `AGENTS.md` 和 `docs/diagrams/`。

**Step 3: 实现最小状态转换 API**

`KnowledgeBaseStore` 增加两个方法：

```python
def queue_for_publish(self, item_id: str) -> KnowledgeItem:
    return self._transition(
        item_id,
        allowed_from={"ready", "failed"},
        status="queued",
    )

def claim_queued_publish(self, item_id: str) -> KnowledgeItem:
    return self._transition(
        item_id,
        allowed_from={"queued"},
        status="running",
    )
```

`_transition()` 在 `self._lock` 和同一 SQLite 事务内完成读取、来源状态检查和更新，失败时不修改记录。保留 `set_status()` 给发布内部终态收敛使用，不扩大公开状态机。

`publish_item()` 开头改为：

```python
try:
    item = store.claim_queued_publish(item_id)
    if not item.ready_for_publish:
        raise ValueError("资料尚未补齐或不可发布")
    # 现有 freeze/update/chunk/index/activate 链路保持不变
except Exception as error:
    current = store.get(item_id)
    if current.status in {"queued", "running"}:
        store.set_status(item_id, "failed", error=str(error)[:1_000])
    raise
```

`publish_knowledge_item()` 改用 `queue_for_publish()`，不再直接 `set_status(..., "queued")`。

**Step 1: 写 Web 边界大小失败测试**

在 `knowledge.py` 导出单一常量：

```python
MAX_KNOWLEDGE_PDF_BYTES = 100 * 1024 * 1024
```

在 `app.py` 增加可独立测试的有界 spool 函数：

```python
@asynccontextmanager
async def _spool_bounded_request(
    request: Request,
    *,
    max_bytes: int,
) -> AsyncIterator[IO[bytes]]:
    declared = request.headers.get("content-length")
    if declared is not None and int(declared) > max_bytes:
        raise ValueError("知识库 PDF 超过 100 MiB 限制")
    size = 0
    with tempfile.SpooledTemporaryFile(max_size=1024 * 1024, mode="w+b") as spool:
        async for chunk in request.stream():
            size += len(chunk)
            if size > max_bytes:
                raise ValueError("知识库 PDF 超过 100 MiB 限制")
            if chunk:
                spool.write(chunk)
        spool.seek(0)
        yield spool
```

实施时同时捕获非数字或负数 `Content-Length`，返回 422，不让 `int()` 异常变成 500。

在 `tests/web/test_knowledge.py` 用可控 async fake request 验证：

```python
class SQLiteSessionRevocationStore:
    def __init__(self, path: Path) -> None:
        self.path = path
        self.path.parent.mkdir(parents=True, exist_ok=True)
        with self._connect() as connection:
            connection.execute(
                """CREATE TABLE IF NOT EXISTS revoked_web_sessions (
                    session_id TEXT PRIMARY KEY,
                    expires_at INTEGER NOT NULL
                )"""
            )

    def contains(self, session_id: str, *, now: int) -> bool:
        with self._connect() as connection:
            connection.execute(
                "DELETE FROM revoked_web_sessions WHERE expires_at <= ?", (now,)
            )
            row = connection.execute(
                "SELECT 1 FROM revoked_web_sessions WHERE session_id = ?",
                (session_id,),
            ).fetchone()
            return row is not None

    def revoke(self, session_id: str, *, expires_at: int) -> None:
        with self._connect() as connection:
            connection.execute(
                "INSERT OR REPLACE INTO revoked_web_sessions(session_id, expires_at) VALUES (?, ?)",
                (session_id, expires_at),
            )
```

实施时 `_connect()` 启用 `busy_timeout`，并使用 context manager 提交。

```python
if session_id in self._revoked or (

    return None
```

```python
def _atomic_write_text(path: Path, content: str) -> None:
    temporary = path.with_name(f".{path.name}.{uuid.uuid4().hex}.tmp")
    try:
        with temporary.open("x", encoding="utf-8", newline="\n") as stream:
            stream.write(content)
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(temporary, path)
    finally:
        temporary.unlink(missing_ok=True)
```
