# Agent 结构化可观测性 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为本地研究 Agent 增加不记录问题正文、查询正文、证据正文或密钥的结构化运行、节点、工具与 Runtime 拦截日志。

**Architecture:** 新增独立的 `agent.observability` 模块，定义稳定事件契约、SQLite best-effort 存储和安全哈希函数。`ResearchAgentRuntime` 记录一次运行的开始、完成、超时和输出校验失败；LangGraph 节点包装器记录节点流转与耗时，工具调用包装器记录工具结果摘要和策略拦截。日志通过依赖注入接入 factory，默认仅写入项目 `data/runtime`。

**Tech Stack:** Python 3.11+、Pydantic、SQLite、LangGraph、pytest
