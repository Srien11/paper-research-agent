# 可复现论文 RAG 检索基线实施计划

> **Codex 执行要求：** 按任务逐项实施并在每个检查点运行测试。若专用计划执行技能不可用，则使用仓库已有的验证式开发流程，仍然保留测试先行、分步验证和小步提交。

**目标：** 将冻结的 80 篇论文语料转换为可追溯、可复现、可量化评测的 RAG 检索基线。

**架构：** 受版权约束的 PDF 保留在 Git 仓库外，通过经过校验的冻结清单引用。先建立确定性的页面、元素和片段产物，再使用同一版本化评测集比较纯向量、混合检索和重排检索，最后才增加答案生成与 Agent 编排。

**技术栈：** Python 3.11+、Pydantic v2、PyMuPDF 或 Docling、SQLite、sentence-transformers、FAISS、rank-bm25、unittest/pytest、GitHub Actions。
