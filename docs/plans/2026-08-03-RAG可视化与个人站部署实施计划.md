# RAG 可视化与个人站部署 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将现有全量 80 篇论文 RAG 接入仅站长可登录的 Web 可视化界面，并从 `zhimoai.online` 项目卡进入真实问答服务。

**Architecture:** 保持现有分块、BAAI/bge-small-en-v1.5 向量、BM25、RRF、英文 Reranker、Qwen 查询改写与回答链路不变。新增常驻 `RAGRuntime` 一次加载 chunks、FAISS 与本地模型；FastAPI 负责站长认证、问答 API、会话和静态前端，Nginx 在 `/paper-research/` 反向代理到仅监听 `127.0.0.1` 的服务。内部语料只保存于服务器私有目录，所有问答与调试 API 均要求签名会话 Cookie。

**Tech Stack:** Python 3.11、FastAPI 0.139、Uvicorn 0.52、原生 HTML/CSS/JavaScript、现有 FastEmbed/FAISS/SQLite/Qwen、Nginx、systemd。
