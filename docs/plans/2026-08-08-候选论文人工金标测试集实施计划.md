# 候选论文人工金标测试集 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 基于本地80篇论文的标题、摘要与必要原文，建立30条人工审阅的候选论文检索金标，并用它评价 Candidate Paper Recall。

**Architecture:** 新增严格的候选金标数据契约，将问题、目标 `corpus_id`、线索范围、难度和简短标注理由保存在 Git 忽略的私有金标目录。20条开发集用于诊断，10条封存测试集只报告聚合指标；候选层主指标只统计 `title_abstract` 可识别问题，正文细节题单独诊断，避免任务定义污染。

**Tech Stack:** Python 3.11+、Pydantic、JSONL、pytest、现有 PaperCard/候选检索器

---

### Task 1: 建立候选金标严格契约

**Files:**
- Create: `src/paper_research_agent/evaluation/candidate_gold.py`
- Create: `tests/evaluation/test_candidate_gold.py`

**Steps:**
1. 先写失败测试，约束唯一问题ID、1至4个唯一目标论文、合法 `C/T` 编号、开发/封存拆分、线索范围和非空简短理由。
2. 运行定向测试确认失败。
3. 实现 Pydantic 模型、JSONL加载器和只输出计数/ID的摘要函数。
4. 运行定向测试确认通过。

### Task 2: 人工阅读与双轮标注30题

**Files:**
- Create (Git ignored): `data/evaluations/gold/candidate-paper-gold-v1.jsonl`
- Create: `reports/RAG候选论文人工金标说明-v1.md`

**Steps:**
1. 从论文卡片按幻觉/事实性、RAG、代码、污染、LLM裁判、安全、智能体、推理等主题分层抽样。
2. 第一轮逐篇阅读标题与摘要，必要时查同论文原文块；撰写不含论文编号、不照抄完整标题的自然中文问题。
3. 第二轮反向核对每道题：仅凭问题能否合理指向全部目标论文；检查相似论文是否应加入目标或干扰项。
4. 标注 `clue_scope=title_abstract` 或 `full_text_detail`；后者不计入候选层主指标。
5. 生成20条开发题和10条封存题；报告中不公开封存题正文。

### Task 3: 验证数据与运行基线

**Files:**
- Create: `scripts/evaluate_candidate_paper_gold.py`
- Create: `tests/evaluation/test_candidate_paper_gold_runner.py`
- Create: `reports/RAG候选论文人工金标基线-v1.md`

**Steps:**
1. 先写失败测试，验证主指标只纳入 `title_abstract`，并分别报告 Recall@5、Recall@8、All-target Hit@8。
2. 实现本地评测脚本；输出不得包含原文、摘要或封存题正文。
3. 校验30条目标ID均存在于80张 PaperCard，题目不含显式 `C001/T001` 编号。
4. 运行开发集与封存集基线，记录转化成功/降级次数及聚合指标。
5. 运行全量测试和本次文件 Ruff。

### Task 4: 安全检查与提交

**Steps:**
1. 确认私有金标JSONL仍被 Git 忽略，提交内容不含论文全文、摘要、密钥、索引或运行数据库。
2. 提交契约、测试、脚本和脱敏聚合报告：`评测: 建立候选论文人工金标基线`。
