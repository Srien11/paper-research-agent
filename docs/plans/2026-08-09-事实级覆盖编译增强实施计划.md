# 事实级覆盖编译增强 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将比较研究的覆盖判断从“论文×维度单元至少有一个事实”升级为“问题派生的原子事实意图逐项满足”，同时消除长上下文前置证据挤占、同论文跨维度证据不可复用和部分覆盖无法补检的问题。

**Architecture:** 规划节点在现有一次调用内，为每个论文×维度单元生成生产可见的原子事实意图；覆盖编译节点仍使用现有一次调用，但输入改为按单元公平分配、同论文可复用的证据视图，并输出事实到意图的显式映射以及 `missing/partial/sufficient/conflicting` 状态。确定性校验器根据意图集合计算缺口，部分覆盖单元也进入现有批量补检队列；答案生成仍只读取已编译台账事实。评测链路新增“已水合但未进入编译器可见上下文”的独立归因，不让上下文截断被误记为模型未编译。

**Tech Stack:** Python 3.12、Pydantic v2、LangGraph、LangChain structured output、pytest、Ruff、mypy。

---

## 不变约束

- 生产节点不得读取私有参考答案、评分金标或评测文本。
- 保持论文语料硬隔离；只允许同一 `corpus_id` 内跨维度复用证据。
- 不提高 24 个检索单元、48 次工具调用、180 秒绝对上限。
- 不增加正常路径规划或覆盖判断的模型调用次数。
- 最终答案仍禁止生成台账外事实，局部失败仍只修补当前维度。
- 旧检查点和旧测试构造的粗粒度 requirement 通过兼容性派生意图读取；新规划必须输出显式意图。

### Task 3: 将覆盖判断升级为事实意图完整性判断

**Files:**
- Modify: `src/paper_research_agent/agent/coverage.py`
- Modify: `src/paper_research_agent/agent/reasoner.py`
- Modify: `src/paper_research_agent/agent/graph.py`
- Test: `tests/agent/test_coverage.py`
- Test: `tests/agent/test_reasoner.py`
- Test: `tests/agent/test_graph.py`

**Step 1: 写失败测试**

覆盖：

- 单元有一个事实但缺少另一个事实意图时必须是 `partial`，不能令整题 sufficient。
- `missing_fact_requirement_ids` 必须精确等于计划意图减去事实已满足意图。
- partial requirement 可以产生 followup。
- followup query 必须包含缺失事实意图，而不是重复整个宽维度。
- 补检后满足全部意图，状态转为 sufficient。

**Step 2: 运行测试确认失败**

Run: `.venv\Scripts\python.exe -m pytest tests/agent/test_coverage.py tests/agent/test_reasoner.py tests/agent/test_graph.py -q`

Expected: FAIL，当前 `bool(cell.facts)` 被当作充分覆盖。

**Step 3: 实现确定性完整性校验**

对每个 cell：

```python
expected = {intent.fact_requirement_id for intent in requirement.fact_requirements}
satisfied = {intent_id for fact in cell.facts for intent_id in fact.fact_requirement_ids}
missing = expected - satisfied
```

- `coverage.covered` 继续表示“存在可用事实”，保持旧字段语义。
- ledger `status` 表示完整性：无事实为 missing，有事实且有缺口为 partial，无缺口为 sufficient。
- 整题 `evidence_sufficient` 只在所有 ledger cell sufficient 时为真。
- followup 允许绑定 missing 或 partial cell。

repair 只能保留有效事实映射；无意图映射且该 cell 只有一个意图时可确定性绑定，多个意图时不得猜测。

**Step 4: 更新 reasoner 提示**

要求模型：

- 每个事实必须映射一个或多个 supplied fact requirement IDs。
- 必须逐项检查所有事实意图。
- partial cell 必须返回精确 missing IDs 和针对缺失事实的补检。
- 不得用同一宽泛事实满足语义不同的多个意图。

**Step 5: 运行聚焦测试**

Run: `.venv\Scripts\python.exe -m pytest tests/agent/test_coverage.py tests/agent/test_reasoner.py tests/agent/test_graph.py -q`

Expected: PASS。
