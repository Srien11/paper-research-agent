# 主图问题无损双语候选检索 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在固定研究图的最前置规划阶段生成不替换原问题的英文检索视图，让论文候选 BM25 与向量检索同时消费完整原文和忠实英文转换。

**Architecture:** 主图传入的 `question` 始终作为唯一权威语义，继续原样进入规划、推理、回答和审计。查询转换器只生成附加 `english_query`，论文候选检索对原文与英文分别执行 BM25+向量召回并跨语言融合；转换失败时完整退回原文路径，不能阻断研究图。

**Tech Stack:** Python、现有 DashScope query rewriter/cache、BM25、FastEmbed、RRF、LangGraph、pytest、Ruff。
