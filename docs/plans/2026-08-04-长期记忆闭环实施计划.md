# 长期记忆闭环 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在现有审批工具上实现可召回、可提议、可更新、可删除且不会污染论文引用的长期记忆闭环。

**Architecture:** 保留 `manage_long_term_memory` 作为唯一存储门禁，将 SQLite 记录升级为带作用域、版本、状态、哈希和替代关系的软删除模型。动态 Graph 在 Router 前增加只读召回，在 Router 完成后仅对明确记忆意图生成结构化候选，再复用现有 `interrupt` 审批节点完成新增或更新；记忆始终标记为 `research_context`，不能成为引用证据。

**Tech Stack:** Python 3.11、Pydantic v2、SQLite、LangChain structured output、LangGraph interrupt/checkpoint、FastAPI。
