# 英文论文候选单路检索修复 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 保留主图完整原问题，但论文候选层只用英文检索视图检索英文标题与摘要，避免中文噪声参与候选排名。

**Architecture:** `PaperCandidateQuery` 同时保存完整原问题和可选英文视图；`HybridPaperCandidateRetriever` 在英文视图存在时只用英文视图执行论文级 BM25 与向量融合，转化失败时才显式降级到原问题。论文确定后的正文证据检索保持现有双语能力，因为生成的图片摘要包含中文；本任务不删除该层中文路。

**Tech Stack:** Python 3.11+、asyncio、确定性 BM25、FastEmbed、unittest/pytest、Ruff
