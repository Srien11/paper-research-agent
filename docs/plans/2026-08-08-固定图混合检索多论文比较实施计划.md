# 固定图混合检索多论文比较 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将本地多论文比较统一收敛到固定研究图，使用带论文范围约束的 BM25＋向量混合检索，并从动态图移除旧的字符串匹配 `compare_papers` 工具。

**Architecture:** 固定图继续按“比较对象 × 比较维度”生成检索步骤，每一步通过 `search_corpus` 调用现有双语混合检索器，并把目标 `corpus_id` 的硬过滤条件传到底层 BM25 和 FAISS 召回。比较证据按目标与维度单元格绑定，无法解析目标范围时关闭失败。动态图的扩展工具目录、Schema 和分发器不再注册 `compare_papers`，主 Agent 通过提示与确定性守卫将本地多论文比较路由到 `local_rag`。

**Tech Stack:** Python 3.11+、Pydantic v2、LangGraph、LangChain、BM25、FAISS、pytest。
