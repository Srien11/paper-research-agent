# 检索 C 基线实施计划

> **供 Codex 执行：** 按测试驱动、最小提交和逐次 CI 的方式完成本计划。

**目标：** 在同一份可追溯片段上实现向量、混合和重排检索，并一次性输出 A/B/C 可比实验。

**架构：** 先将确定性文档元素合并为章节内片段，再以同一片段 ID 建立 BM25 和
FAISS 向量索引。检索 C 使用倒数排名融合召回候选，并以交叉编码器重排；关闭稀疏
召回或重排即可得到 A、B 两个消融基线。正文、模型和索引只保存在 Git 忽略的本地目录。

**技术栈：** Python 3.11+、Pydantic v2、NumPy、FastEmbed 0.8、FAISS CPU 1.14、
SQLite、unittest。
