# 统一会话解释与多能力研究 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use coding-agent execution and verification guidance task-by-task.

**Goal:** 让每轮请求默认获得有限共享上下文，由结构化模型同时完成历史依赖、独立问题和研究能力规划，并允许本地论文与动态研究共同执行。

**Architecture:** Conversation Store 继续作为唯一事实账本；Coordinator 无条件构造最近窗口、Episode 与远距候选，ConversationRuntime 用一次结构化模型调用生成 `TurnInterpretation`。策略层只校验候选 turn ID、会话隔离、知识库开关和能力可用性，执行层按能力计划串联 Local RAG 与动态研究。

**Tech Stack:** Python 3.11+、Pydantic v2、FastAPI、httpx、SQLite、现有 RAGRuntime/ConversationRuntime、unittest/pytest。
