# 论文研究智能体整体测评基线实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 建立覆盖数据、检索、RAG、Agent、记忆、安全、Web 和性能的可复现评测标准，并运行当前环境可测项目形成中文基线报告。

**Architecture:** 复用现有银标检索集和 A/B/C runner，新增不保存回答正文的端到端 RAG runner；用自动化测试统计确定性能力，用真实 RAG 查询统计质量代理指标和延迟。所有无法由现有金标支持的维度明确标记为 N/A，不用 LLM 主观分数冒充金标。

**Tech Stack:** Python 3.14、Pydantic、现有 RetrievalService/RAGRuntime、unittest、JSONL、Markdown。

---

### Task 1: 冻结整体测评标准

**Files:**
- Create: `evaluation/整体测评标准-v1.md`

**Step 1:** 定义八个评测维度、数据切片、指标公式、硬门禁和建议阈值。

**Step 2:** 明确银标开发集、回归集和密封金标集的用途边界。

**Step 3:** 检查 `docs/数据与评测政策.md`，确保报告不包含全文、证据正文或本地绝对路径。

### Task 2: 增加端到端 RAG 评测 runner

**Files:**
- Create: `src/paper_research_agent/evaluation/end_to_end.py`
- Create: `tests/evaluation/test_end_to_end.py`
- Create: `scripts/evaluate_end_to_end.py`

**Step 1:** 先写延迟分位数、证据命中、错误聚合和安全输出测试。

**Step 2:** 运行测试并确认缺少实现时失败。

**Step 3:** 实现逐题调用 `RAGRuntime.ask` 的 runner，只保存 ID、状态、来源计数、命中指标、Token 和延迟。

**Step 4:** 运行测试并确认通过。

### Task 3: 运行可复现自动评测

**Files:**
- Generate locally: `data/evaluations/runs/*.json`
- Generate locally: `reports/整体测评基线-v1.md`

**Step 1:** 运行检索 A/B/C 基线和中英图片诊断集。

**Step 2:** 运行路由、工具、审批、记忆、Web、安全相关测试并统计通过率。

**Step 3:** 使用冻结评测集运行真实端到端 RAG 查询，记录 P50/P95、成功率、证据命中和引用结构合格率。

**Step 4:** 保存命令、环境指纹、数据集指纹和限制说明。

### Task 4: 形成总报告并复核

**Files:**
- Create: `reports/整体测评基线-v1.md`

**Step 1:** 汇总实测指标，明确区分“实测”“测试代理指标”“未测”。

**Step 2:** 应用硬门禁，只有安全门禁通过时才给综合评分。

**Step 3:** 运行 `git diff --check`、相关单元测试和报告数据一致性检查。

**Step 4:** 不提交 Git；保留用户现有工作区改动。
