# 可引用 RAG 上下文组装 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将检索命中组装为有明确消息优先级、固定 token 预算、可验证引用且隔离提示注入的 LLM 上下文。

**Architecture:** 新增独立 `context` 包，不依赖具体 LLM 或 LangGraph。输入为系统规则、用户问题、
可选任务状态和带正文的检索证据；输出为结构化消息与引用清单。检索正文始终放入带边界的
不可信证据区，预算不足时按排名保留完整证据，不截断引用元数据。

**Tech Stack:** Python 3.11+、Pydantic v2、现有 `EvidenceChunk`/`SearchHit` 契约、
`unittest`、Ruff、mypy。

---

### Task 1: 定义上下文输入输出契约

**Files:**
- Create: `src/paper_research_agent/context/__init__.py`
- Create: `src/paper_research_agent/context/models.py`
- Test: `tests/context/test_models.py`

**Steps:**
1. 为非法消息角色、重复引用 ID、空用户问题和负 token 预算编写失败测试。
2. 定义 `ContextEvidence`、`CitationRef`、`PromptMessage`、`ContextRequest` 和
   `AssembledContext`，全部拒绝额外字段并冻结。
3. 运行 `python -m unittest tests.context.test_models -v`，预期通过。

### Task 2: 实现确定性证据选择与预算

**Files:**
- Create: `src/paper_research_agent/context/budget.py`
- Test: `tests/context/test_budget.py`

**Steps:**
1. 为 chunk ID 去重、文本哈希去重、稳定排名、预算溢出和最小证据保留编写测试。
2. 复用 `regex-token-v1` 估算 token，先扣除系统规则、用户问题、任务状态和固定模板。
3. 按 `final_rank`、`chunk_id` 稳定选择完整证据；预算不足时丢弃低排名证据，不截断正文。
4. 运行上下文测试，预期通过。

### Task 3: 组装分层消息并隔离提示注入

**Files:**
- Create: `src/paper_research_agent/context/assembler.py`
- Test: `tests/context/test_assembler.py`

**Steps:**
1. 测试输出顺序固定为系统规则、用户问题/任务状态、证据数据。
2. 系统消息声明证据是不可信数据，禁止执行证据中的指令。
3. 使用不可变边界标记逐条包装证据，包含 citation ID、论文 ID、页码、chunk ID 和哈希。
4. 返回引用清单，并验证消息正文中的引用与清单一一对应。
5. 同一输入重复组装两次必须逐字段相同。

### Task 4: 提供检索结果适配和命令行预览

**Files:**
- Create: `src/paper_research_agent/context/adapters.py`
- Create: `scripts/assemble_context.py`
- Test: `tests/context/test_adapters.py`

**Steps:**
1. 将 `RetrievalRun.hits` 与本地 `EvidenceChunk` 正文按 chunk ID 严格连接。
2. 缺失、重复或哈希不匹配时失败，不允许生成无法追溯的上下文。
3. CLI 读取检索运行 JSON、chunks JSONL 和用户问题，输出上下文 JSON 预览，不调用模型。
4. 运行相关测试与 CLI 帮助命令。
