# 发布门禁

本项目同时维护冻结论文检索门禁和主 Agent 混合研究门禁。生产启用外部学术检索前，下面各项
必须同时成立；不能用离线单元测试代替真实 Provider 冒烟，也不能通过放宽金标掩盖失败。

## 1. 冻结语料与检索

1. 完整测试套件在无网络、`PRA_SCHOLARLY_MODE=offline` 环境通过。
2. 两次切块构建的 `chunks.jsonl` 和 `paper_cards.jsonl` SHA-256 完全一致。
3. 索引清单记录 embedding 模型与修订、维度、片段构建哈希、文件哈希和 CPU 指纹。
4. A/B/C 使用同一查询集、同一索引与相同 `top_k`，结果记录完整实验指纹。
5. 诊断报告明确银标开发集、单审阅者、图片与 OCR（光学字符识别）边界。
6. 本地回答引用只能来自本轮真实 chunk 白名单；外部结果和模型背景知识不得进入本地引用列表。

## 2. 并行执行与原子性

1. 三类混合措辞都必须规划为同一个 `parallel_group_id` 下的 `local_rag + dynamic_tools`，顺序
   固定为本地、外部，且禁止第三个 `direct_chat`。
2. 使用带启动屏障的真实执行器验证两个分支重叠；不能只检查任务列表或 mock（模拟）标记。
3. 20 轮 `200 ms + 200 ms` 工作负载的批次 P95 小于 320 ms，两支启动差 P95 小于 50 ms。
4. 并行分支不得直接修改共享 workspace；汇合后只提交一个新版本，不允许半提交。
5. 一支异常或超时不得取消已成功兄弟分支；重试只重跑失败任务。
6. 暂停和取消在当前批次汇合后生效，继续执行不得重跑成功分支。

## 3. 学术网络权限与就绪状态

1. 并行动态分支的风险白名单严格等于 `network_read`，工具名白名单严格等于四个学术工具。
2. 写工具、本地读取、计算工具和任意其他 MCP 网络工具在 Provider 调用前稳定拒绝，执行次数为
   0，且不创建审批记录。
3. `CapabilityReadiness` 必须区分“动态图存在”、offline、live ready、live 请求超时和 live
   请求失败；超时或失败不得投影为成功。
4. `PRA_SCHOLARLY_MODE` 默认 `offline`。只有管理员显式设为 `live` 后才能做公开论文元数据
   请求；它提供的是 Semantic Scholar/Crossref 学术检索，不是通用网页搜索。
5. 真实冒烟只记录 Provider ID、状态、计数、耗时和 `network_accessed`，不保存查询、原始响应
   或密钥。未获联网授权时必须在验收报告中明确记为“未执行”，不得伪造通过。

## 4. 综合、引用与降级

1. 混合成功场景必须由最终综合模型调用一次，把模型自身知识、本地证据和外部研究上下文合成
   一个回答；模型参与不表示需要额外创建 `direct_chat` 子任务。
2. 模型概念背景和推论不分配来源 ID；本地证据保留原引用，外部结果只标记为
   `research_context`。
3. 外部分支失败时保留本地回答，并确定性显示“外部学术核验未完成”。
4. 本地分支失败时保留外部研究，但不得生成本地引用。
5. 两支都失败、综合模型可用时只返回无引用背景回答并标记 `model_background_only`；综合模型也
   失败时才令运行失败。
6. 时效性事实必须有本轮外部学术证据才算已核验，不能依赖模型参数知识或本地旧论文替代。

## 5. 事件、界面与隐私

1. `parallel_group_started` 先于两个任务完成，`parallel_group_completed` 后于两个任务完成；
   事件 ID 唯一、连续、幂等，终态只有一个 `done`。
2. 并行事件 detail 只含稳定非敏感组 ID、任务数、返回数、耗时和降级状态，不含问题、查询、
   论文正文、Provider 原始载荷、本地路径或密钥。
3. 前端同时显示两个 running 节点及“并行 1/2”“并行 2/2”；最终回答必须等到批次汇合后显示。
4. 部分成功显示 warning（警告）而不是系统错误；暂停提示明确“当前并行批次完成后暂停”。
5. 至少完成一次真实浏览器宽屏验收；若支持移动端布局，同时检查移动视口不遮挡任务状态。

## 6. 配置、回滚与一致性

1. `PRA_PARALLEL_HYBRID_RESEARCH_ENABLED` 默认 `false`，只接受大小写不敏感的
   `true` / `false`；`1`、`yes`、空白和其他非法值必须令启动失败。
2. 开关为 `false` 时，混合请求以 `parallel_hybrid_disabled` 关闭失败，两个执行器调用数均为
   0；不得串行执行或静默二选一。单任务行为保持不变。
3. 回滚演练不得删除 SQLite、checkpoint、论文数据或已完成任务，也不得手工改写 workspace。
4. Runtime 返回的 `workspace_version` 必须与原子提交结果一致，包括已提交的失败结果。
5. 主 Agent 整体异常仍可使用 `PRA_MAIN_AGENT_MODE=legacy` 回滚；该开关与并行功能开关互相独立。

## 7. 最终命令与工作树审计

使用项目虚拟环境执行：

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
.\.venv\Scripts\python.exe -m pytest -p no:cacheprovider -q
.\.venv\Scripts\python.exe -m ruff check src tests
.\.venv\Scripts\python.exe -m mypy src
git diff --check
git status --short
```

Git 中不得包含 PDF、正文 JSONL、FAISS、SQLite、NumPy 向量、模型权重、密钥、本地绝对路径或
Provider 原始响应。CI 会阻止常见私有或生成产物扩展名，发布者仍须人工检查 `git status` 和
最终 diff，因为扩展名规则不能覆盖所有数据泄露形式。
