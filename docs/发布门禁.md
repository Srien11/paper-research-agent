# 检索基线发布门禁

发布检索基线提交前必须满足：

1. `python -m unittest discover -s tests -v` 在无网络环境全部通过。
2. 两次切块构建的 `chunks.jsonl` 和 `paper_cards.jsonl` SHA-256 完全一致。
3. 索引清单记录 embedding 模型与修订、维度、片段构建哈希、文件哈希和 CPU 指纹。
4. A/B/C 使用同一查询集、同一索引与相同 `top_k`，结果记录完整实验指纹。
5. 诊断报告明确银标开发集、单审阅者和图片 OCR 边界。
6. Git 中不得包含 PDF、正文 JSONL、FAISS、SQLite、NumPy 向量、模型权重或密钥。

CI 会阻止常见私有或生成产物扩展名。发布者仍须检查 `git status`，因为扩展名规则不能
覆盖所有数据泄露形式。
