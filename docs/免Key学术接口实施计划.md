# 免 Key 学术接口接入

本次按已确认的 Crossref + arXiv 方案实施，入口沿用私人研究台的问答和现有四个学术工具。
用户可以要求“在 arXiv 检索论文”或“解析 DOI”。不新增公开接口，不自动下载或导入 PDF。

1. 在学术工具输入中增加可选 `source`，默认 `auto`，支持 Crossref、arXiv 和既有
   Semantic Scholar；明确来源时只调用该来源，避免返回另一数据库的结果。
2. 增加 Crossref（搜索、DOI 解析、有限参考文献、出版更新元数据）与 arXiv
   （搜索、ID 解析）适配器，统一书目字段和低信任上下文。标题解析返回候选，不冒充精确匹配。
3. 无 Key 的 live 模式注册 Crossref 和 arXiv；有 Key 时保留 Semantic Scholar。
   默认配置仍为 offline，本机验收后启用 live。设置 offline 即可回滚联网能力。
4. 固定官方 HTTPS 端点，限制响应大小；Crossref 保守限速，arXiv 请求至少间隔 3 秒；
   5 分钟内存缓存最多 128 项，无持久化、无自动重试。超时、限流、格式错误安全降级。
5. 补充契约、来源路由、缓存/限速、错误、年份和引用图边界测试，运行回归与静态检查，
   再以公开书目查询进行真实联网验收，记录状态、数量与真实耗时。

外部元数据不能替代本地全文证据。Crossref 的摘要与参考文献可能缺失，不支持完整反向引用图；
出版更新信息不构成“未撤稿”的保证。arXiv 不提供引用图或撤稿核查。
保留既有 Semantic Scholar 作为可行替代；OpenAlex 接入、PDF 入库、UI 新按钮不在本次范围内。
网络只发送用户明确要求的检索式和公开标识符，不发送证据、私人历史或长期记忆。
