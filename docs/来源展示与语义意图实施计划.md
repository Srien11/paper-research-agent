# 来源展示与语义意图改进

用户已确认同时实施来源卡片与模型语义判定信息需求。

1. 学术工具返回后台构造的有界来源记录：数据库、调用状态、查询时间、缓存/实时标识、
   论文标题、标识符与官方链接。仅投影书目信息，不保存查询参数、摘要或 Provider 原始响应。
2. 来源记录进入 DynamicToolArtifact 和安全产品事件，前端在回答下方展示来源卡片；
   使用现有事件与历史恢复机制，刷新不重新请求模型，不给旧记录伪造来源。
3. 扩展现有 TurnInterpreter 输出的信息需求与数据库偏好，沿用该次模型调用。
   未明确可直接回答的请求进入现有语义规划链路，普通问候和概念解释保留快捷路径。
   模糊请求可能因此使用原有解释/规划调用；不新增独立分类模型或重复解释阶段。
4. 规划器结合高置信语义需求与用户明确限制选择本地/外部/混合任务；明确禁止联网、
   required 模式、只读白名单、审批与引用校验继续由程序强制执行。模型失败或置信度不足
   时保留既有确定性降级，不赋予写权限。普通概念解释不因提到论文而强制联网。
5. 验收覆盖 API 来源真实性、缓存、来源链接白名单、跨会话隔离、历史/刷新恢复，以及
   自然表达的文献需求、通用解释、禁止联网、required、模型错误与低置信度。

触发入口仍为私人研究台的自然语言问答，没有新增公开入口或自动下载。
技术选型使用现有 Pydantic 契约、产品事件与 DOM 渲染；独立意图模型/新触发按钮作为
可行替代，本次不采用。书目记录随会话保存与清除，缓存仍仅存在内存。
回滚代码可关闭新展示与语义字段消费，新增字段均提供空默认，旧历史继续读取。
