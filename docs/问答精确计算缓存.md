# 问答精确计算缓存

本地论文问答在原有查询改写 SQLite 缓存之外，增加三层实例内存缓存。新启动的运行实例默认启用，无需新增页面或操作入口；当前运行中的服务需要重新加载代码才生效。

| 层级 | 命中条件 | 保存结果 | 容量 |
| --- | --- | --- | ---: |
| 查询向量 | 相同模型、版本、完整查询 | 数值向量 | 256 |
| 重排分数 | 相同模型、版本、完整查询、候选全文和顺序 | 数值分数 | 256 |
| 证据评估 | 相同模型实例及生成设置、问题、完整计划、完整检索/证据记录、剩余步骤预算 | 已校验的结构化决策 | 128 |

三层都采用五分钟绝对有效期和容量淘汰，命中不会续期。有效期是逻辑失效：下次读写清除过期项，空闲时不承诺立即物理擦除。服务重启自然清空缓存。原有改写缓存有效期及隐私限制保持不变。

缓存键为 SHA-256，不保留问题、查询或证据正文作为键；不新增磁盘缓存、原始 Provider 请求/响应日志或公开全文。评估值可能包含下一条检索式及比较事实，仅保留在本地实例内存；生产工厂在清空会话和关闭运行实例时清除评估缓存。一个会话清空会保守清除该实例所有评估缓存，影响命中率，不影响答案校验。

每个模型实例有自己的缓存，模型版本更换、新实例和重启不会继承旧实例结果。重排分数绑定实际候选正文及顺序，查询向量与重排不缓存最终检索列表：当前索引、过滤、版权、证据装载和最终引用校验仍正常执行。数值结果返回副本，避免调用者改写缓存。

证据评估键包含实际证据文本及其声明哈希，不能仅凭上游重用的文本哈希命中；还包含索引版本、范围、证据顺序和版权元数据。命中后重新解析结构、校验计划覆盖与证据归属，并保留缺失事实追问检查，返回深拷贝。

实施中发现普通研究评估原先混入了比较任务指令，输出比较字段后会被普通研究契约拒绝，触发重试与修复，因而无法安全缓存。已将普通研究初始和重试指令改为普通研究规则，明确比较字段为空，要求逐项检查问题与条件；比较编译器及其校验保持原路径。缓存提示词版本随之更新。

异常不会缓存；所有尝试均有效且未修复、未编译失败、未检索降级的评估结果才允许入缓存。缓存失效或缓存结果不合规时回到正常模型路径。最终回答继续调用现有回答模型，不缓存答案，不合并证据评估，不开启独立检索批量模式。

`PRA_EXACT_CACHE_ENABLED=false` 可关闭三层新增缓存，重启实例后生效；恢复 `true` 或不设置即可启用。原有改写缓存不受该开关影响。适配器和证据评估器还支持 `cache_entries=0`，用于隔离测试。容量和开关在实例创建时固定。

命中收益主要属于完全相同输入的重复请求。首次新问题、变更过的计划或证据、已修复/降级结果通常不命中。结构合法不等于语义正确，复用决策可能保留首次模型判断的错误；不能用缓存命中率替代人工校准与现有质量门禁。

诊断计数分别位于查询向量、重排和评估缓存对象的 `hits`、`misses`。这些计数是缓存查找次数，不是模型内部重试次数。缓存命中保留原决策的编译审计，审计描述首次结果的校验过程，不表示当前命中调用再次请求了模型。
